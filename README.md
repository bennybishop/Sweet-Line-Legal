# Sweet Line legal pages

Public privacy and deletion information for Sweet Line: Idle Candy Factory (com.indieben.sweetline), Benjamin Dehant Games.

## Enable GitHub Pages
Settings > Pages > Build and deployment > Source: Deploy from a branch > Branch: main / (root) > Save.

After deployment, verify these URLs in a signed-out browser:
- https://bennybishop.github.io/Sweet-Line-Legal/privacy.html
- https://bennybishop.github.io/Sweet-Line-Legal/data-deletion.html

Use the privacy URL in Google Play and Meta, and the deletion URL in Meta's data-deletion instructions field. Keep this repository public if using GitHub Free Pages. Do not include application credentials, signing keys or private game source here.

## Scope and release checks
These pages reflect the inspected Android classic integration on 5 October 2026: adult opt-in; Firebase statistics; optional Meta advertising measurement; no Google ADID collection or Google ad personalization; no game account, real purchases or ad serving SDK. Reassess declarations if implementation changes.

Before production: confirm publisher/contact details, provider retention settings and deletion processes; align Play Data safety and target audience declarations with the actual release. The policy does not invent a fixed retention setting that has not been verified. Set and document the chosen provider retention periods, then make the policy more specific where applicable. This repository is not a guarantee of legal compliance.

The current APK contains an offline privacy page. A release build should include the current complete policy and public links. Enabling GitHub Pages does not itself modify the APK.
